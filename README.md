# 小海拉 Codex Pet

以《深空之眼》海拉·悼亡之蝶为视觉参考制作的 Codex Desktop 自定义动画宠物。

## 当前版本

- Codex 宠物协议：V2
- 图集：`1536 × 2288` WebP，`8 × 11` 网格
- 单格：`192 × 208`
- 动画：idle、左右移动、挥手、跳跃、失败、等待、工作、审阅
- 注视方向：16 个顺时针方向

可直接安装的宠物包位于 `pet-package/`。将该目录复制到 Codex 本地宠物目录并命名为 `xiao-haila`，然后在 Codex 的“设置 → 宠物”中刷新并选择“小海拉”。

## 工程结构

- `pet-package/`：可直接安装的成品包
- `final/`：PNG、WebP 图集及验证结果
- `frames/`：拆分后的最终动画帧
- `decoded/`：各阶段生成和解码的动画条带
- `prompts/`：角色基准、动画行与返修提示词
- `references/`：角色素材、标准形象和布局参考
- `qa/`：动画预览、方向盲测与质量检查记录

## 已知行为

Codex Desktop `26.908.4834.0` 会在鼠标悬停时把 `jumping` 动画固定播放三次。当前 V2 宠物清单没有重复次数配置；若要改成一次，需要修改桌面应用运行逻辑，而不是修改本仓库的 `pet.json`。
